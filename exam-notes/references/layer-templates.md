# Layer Templates

Follow these precisely. Skip a section only if the source genuinely has
nothing fitting it (e.g., no formulas in a purely conceptual topic).

---

## LAYER 1 — 🗺️ ROADMAP

### 1A. 📖 The Story
- 3-5 sentences narrating the entire material as one connected story
- Mention every major topic by name, show how they relate
- Conversational: "This is basically about... It starts with... which leads
  to... The key insight is..."

### 1B. 🗂️ Concept Map
Text-based visual showing all topics and their relationships:
```
Main Theme
├── Topic A (foundation)
│   └── Subtopic A1 → feeds into Topic C
├── Topic B (contrast to A)
├── Topic C (builds on A + B)
└── Topic D (applies C)
```
Use → for flow/dependency, labels in parentheses for relationships.
Every source topic must appear.

### 1C. 🧱 Prerequisites
- What the material assumes you already know
- One-line refresher per prerequisite: "[Concept] — reminder: [definition]"
- If none: "Self-contained — no prior knowledge needed"

### 1D. 🎯 High-Yield Targets
5-7 most likely exam concepts. Numbered, one-line description each.
Basis: source emphasis, formula/process presence, cross-topic connections.

### 1E. 🚨 Survival Priority
If running out of time, read in this order:
1. Speed Review (Layer 3) — ~15 min
2. All 🔴 sections in Build-Up
3. 🟡 sections if time remains
4. 🟢 only if extra time

## LAYER 2 — 🏗️ BUILD-UP

### Per-Topic Template

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔷 TOPIC NAME
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**⏱️ Importance:** 🔴 Critical / 🟡 Important / 🟢 Good to Know

#### 🎬 Setup (every topic, 1-2 sentences)
- What is this about? Why does it exist? How does it connect to previous topic?
- No jargon — this is the entry ramp

#### 📌 Core Concepts
Per concept:

- **Term** (plain definition)
  - 💡 **Analogy:** "Think of it like..." [🔴 required, 🟡 if natural, 🟢 skip]
  - 🧠 **Memory hook:** mnemonic / image / acronym [🔴 required, 🟡🟢 skip]
  - ⚡ **Key insight / Why it matters:** the non-obvious thing + its significance [🔴 required, 🟡 if present, 🟢 skip]
  - 🎯 **Exam angle:** how tested [🔴 required, 🟡 brief, 🟢 skip]

Rules:
- One idea per bullet
- Show relationships: → (causes), ⇄ (mutual), vs. (contrast)
- 🟢 concepts: **Term** (definition) — one-line note. That's it.
- Adapt depth to each topic's complexity

#### 📝 Formulas
When source has a formula:

$$formula$$

- **Variable** → meaning → unit
- 💡 *"This basically says..."*
- 📖 **Quick example:** simple numbers, show computation
  (source example → *📖 From source*; created → *💡 Added example*)
- ⚠️ **Watch out:** common errors, unit traps
- Preserve: units, sign conventions, boundary conditions, assumptions

#### 🔄 Processes
When source describes a sequence:

```
📥 Input: [starting point]
  ↓
Step 1: [Action] → [what happens / why]
  ↓
Step 2: [Action] → [what happens / why]
  ↓ ⚠️ Decision: if X → 3a; if Y → 3b
  ↓
Step 3: [Action] → [result]
  ↓
📤 Output: [end point]
```

- 💡 **Why this order:** logic behind sequence
- ⚠️ **Common mistake:** which step goes wrong, how
- Describe each step in straightforward terms

#### 📊 Comparison Tables
Create when 2+ related concepts exist:

| Feature | Concept A | Concept B |
|---|---|---|
| Definition | ... | ... |
| Key difference | ... | ... |
| When it applies | ... | ... |
| ⚠️ Common confusion | ... | ... |

Add/remove rows based on source emphasis.

#### 📐 Diagrams & Figures
When source has a visual:

**📐 Figure: [description]**
- Components, relationships, what it illustrates, how to read it
- Text-based recreation when possible

#### 📜 Proofs & Derivations
- **Proving/deriving:** state end result first
- **Key steps:** numbered with justification
- 💡 *"This is really showing that..."*
- 🎯 *"Exam: memorize steps [X] and [Y] — non-obvious ones"*

#### 📖 Source Examples
- *📖 From source:* summarize setup → method → result
- What it demonstrates, the method used, possible exam variations

#### 🗂️ Classifications & Lists
- Every item: name → description → distinguishing feature
- 🧠 Memory hook for the full list (acronym from first letters, etc.)
- State basis of classification

#### Supporting Details
- Subtopics, elaborations, sub-cases not in Core Concepts
- Nested under parent ideas
- All remaining source details placed here — nothing omitted

#### 🛑 Edge Cases & Traps
- Exceptions, boundary conditions, limitations
- ⚠️ **Exam trap:** ❌ *wrong thinking* → ✅ *correct approach*
- Ambiguities flagged with interpretation

#### 🔗 Connections (every major topic)
- ⬅️ **Builds on:** [prior concept + brief reminder]
- ➡️ **Leads to:** [later concept using this]
- ↔️ **Compare with:** [similar/contrasting concept in this material]
- 🌍 **Real-world:** [concrete example — label *🌍 Added example* if not from source]

#### ❓ Exam-Style Questions

| # | Question | Type | Answer |
|---|---|---|---|
| 1 | [Recall or conceptual] | Remember/Understand | ... |
| 2 | [Application or comparison] | Apply/Analyze | ... |

For 🔴 topics: 2-3 questions. For 🟡: 1-2. For 🟢: 0-1.

#### 🔀 Bridge (between every consecutive pair of topics)
One sentence: "Now that you understand [A], next we see [B] which..."
If next topic is harder: "⚠️ Next section is more complex — take it slowly."

## LAYER 3 — 🏁 SPEED REVIEW

~15-minute scannable reference. Compresses — never duplicates Layer 2 verbatim.

### 3A. 📖 60-Second Story
5-7 sentences. Refined version of Roadmap story. Mention every major topic.

### 3B. 📌 Master Term Sheet

| Term | Definition (≤10 words) |
|---|---|
| ... | ... |

Every key term, ordered by topic sequence.

### 3C. 📝 Master Formula Sheet

| Formula | Plain English | Key Trap |
|---|---|---|
| $$...$$ | "Says..." | ⚠️ ... |

Every formula. Include conditions in parentheses.

### 3D. 🎯 Top Exam Predictions
5-7 most likely questions. Each: concept + question format + one-line answer.

### 3E. ⚠️ Master Trap List
All ❌→✅ pairs from entire notes. Most dangerous first.

### 3F. 🧠 Memory Hooks — Quick Fire
Every mnemonic/image/acronym from the notes, listed in order. Scan in 2 min.

### 3G. 🔗 Connection Chain
```
Topic A →(relationship)→ Topic B →(relationship)→ Topic C → ...
```
One chain linking all topics. The skeleton of the material.

### 3H. ❓ Rapid-Fire Q&A
8-12 highest-yield questions across all topics. One-line answers. Mixed types.
