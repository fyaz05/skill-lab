# Quality Checklist

Run every item before delivering. Fix gaps.

## Coverage
- [ ] Every heading and subheading from source → represented
- [ ] Every definition → captured with plain-language explanation
- [ ] Every rule, law, principle → stated with conditions
- [ ] Every formula → variables, intuition, worked example
- [ ] Every process → numbered steps with logic
- [ ] Every source example → included (summarized if long)
- [ ] Every diagram/table/figure → translated (components, relationships, purpose)
- [ ] Every classification/list → all items preserved
- [ ] Every assumption, condition, constraint → stated
- [ ] Every comparison source makes → captured (preferably as table)
- [ ] Units, sign conventions, boundary conditions → preserved
- [ ] Every proof/derivation → key steps + intuition

## Encoding
- [ ] Every 🔴 concept → analogy + memory hook + key insight/why it matters + exam angle
- [ ] Every 🟡 concept → analogy or key insight + exam angle
- [ ] Every 🟢 concept → definition + one-line note
- [ ] Comparison tables → wherever 2+ related concepts exist
- [ ] Exam questions → included per topic (2-3 for 🔴, 1-2 for 🟡, 0-1 for 🟢)

## Structure
- [ ] Layer 1 (Roadmap) → story, concept map, prerequisites, targets, priority
- [ ] Layer 2 (Build-Up) → per-topic template used for every topic
- [ ] Layer 3 (Speed Review) → all 8 subsections (3A-3H)
- [ ] Importance ratings (🔴🟡🟢) → every topic
- [ ] Bridge sentences → between every consecutive topic pair
- [ ] Connections → every major topic (backward, forward, cross, real-world)

## Language
- [ ] Every technical term → defined on first use
- [ ] Term in header → defined in first bullet under header
- [ ] No unexplained jargon
- [ ] Non-technical vocabulary → simple words used
- [ ] No fabricated facts — additions labeled
- [ ] Ambiguities → flagged with ⚠️
- [ ] Bold → only per Bold Policy
- [ ] Emojis → only from Visual System table, no decorative use
- [ ] No mechanical emoji repetition — varied placement
- [ ] Emojis in headers/labels; symbols (→ ⇄ vs.) in body
- [ ] Fragments preferred over full sentences
- [ ] Source order preserved (or labeled "structure added" if source unstructured)
- [ ] No meta-commentary anywhere

## Conciseness Check
- [ ] 🟢 items → definition + one line only, nothing more
- [ ] 🟡 items → no more than: definition + analogy OR insight + brief exam angle
- [ ] No information repeated between Layer 2 and Layer 3
- [ ] Speed Review compresses, not copies
- [ ] Fragments used where full sentences aren't needed

## Completeness Cross-Check
- [ ] Count topics in source → count 🔷 headers in notes → match?
- [ ] Count formulas in source → count in notes → match?
- [ ] Count source examples → count 📖 labels → match?
- [ ] Count figures in source → count 📐 labels → match?
- [ ] Master Term Sheet → every bolded term from Build-Up included?
- [ ] Master Formula Sheet → every formula from Build-Up included?
- [ ] Memory Hooks Quick Fire → every 🧠 from Build-Up included?
- [ ] Connection Chain → every 🔷 topic included?
